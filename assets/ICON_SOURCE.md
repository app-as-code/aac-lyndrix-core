# Icon source

The icon is the official Lyndrix logo from the upstream repository
`lyndrix-platform/lyndrix-core`, file `app/assets/icons/logo.svg` (main branch).
It was downloaded unchanged; no icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `app/assets/icons/logo.svg` | Project logo (includes its own dark background) |

No light or dark variant exists upstream, so only one file is provided. The logo has an
opaque dark background, so it stays readable in both light and dark mode.

Download URL:

- https://raw.githubusercontent.com/lyndrix-platform/lyndrix-core/main/app/assets/icons/logo.svg
