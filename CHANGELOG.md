## [0.0.1]

### Added

- App-as-Code service definition for Lyndrix Core 1.12.0 with `api` and `runner` roles.
- Dependencies: Lyndrix React UI 1.8.0, MariaDB 12.2.2 and HashiCorp Vault 2.2.1.
- Web API on port 8081 and runner on host port 8082, with Traefik routing and automatic DNS.
- README with configuration reference and project icon.
